# e-plantShopping

**Paradise Nursery** is an online plant shop built with React and Redux Toolkit, created as the final project for the IBM Skills Network React course.

## Overview
- A landing page with a background image, a company description (About Us) and a Get Started button
- A product listing page with house plants grouped into categories (Air Purifying, Aromatic, Medicinal and more), each shown on a card with an image, name, description, price and an Add to Cart button
- A navbar with links to Home, Plants and a Cart icon that shows the number of items in the cart
- A shopping cart page where you can increase or decrease quantities, delete items, see each item's subtotal and the cart total, and use Continue Shopping or Checkout

## Tech stack
- React (Vite)
- Redux Toolkit and React Redux
- CSS
